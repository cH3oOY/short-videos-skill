# 原作改编与剧本创作

## 先锁定原作，再决定如何拍

1. 标注输入范围和 `SRC` 锚点（段落、页码或用户给出的章节位置），将「原文明示」「可合理推导」「未知」分开。提取角色目标、阻力、关键选择、选择的后果、视角、信息揭示时机和不可改变的设定。原文与用户授权有冲突时先说明，不把授权改动冒充原作事实。
2. 用一句话确定这段短片讲什么，再列原作核心节拍：人物想要什么 → 遇到什么 → 如何选择 → 局面怎样改变。片段可以保留原有的开放结尾；不为凑完整三幕或追求反转补写后续。片长压力先删重复表达或压缩说明，保留关键选择及因果；塞不下就给建议时长或拆集边界。
3. 把旁白式说明和心理描写转成可拍的行动、道具、对白、停顿或声音。原文已有有效动作时不额外发明替代事件。对白写人物此刻想达成什么，保留原作辨识度；没有原作依据时不要借台词替角色解释动机。不给原作没有的闪回、幻觉或画外音，除非作为明确标注的设计提案。
4. 逐场写完成度足够拍摄的剧本：`SC01｜内/外景｜地点｜日/夜`，随后写现在时的画面动作、说话人、对白、必要的画外声或停顿。一场至少承担一个信息、情绪或选择的变化。正文负责「观众看到、听到什么」，详细机位和镜头编号留给导演台本。

## 交付与校对

- 给出片名或章节标识、一句话故事、成片时长假设、原作锚点表。锚点建议列 `SRC｜原文位置｜事件/关系｜保留或设计性转译`。
- 交付完整剧本正文，不用梗概代替；另给 `改动｜所在场次｜对应 SRC｜理由｜是否影响原作事实`。已授权改动和待确认方案分列。没有新增台词、事件或重排也如实注明。
- 实读关键对白，再留停顿和必要动作时间。剧本没有明说的事不直接交给观众，除非有明确、可见或可听的线索。检查开场是否从原作中最合适的行动进入，结尾是否保留原作给这一段的落点。
- 默认用易读中文剧本。仅在用户点名 `.fountain` 或需要软件交接时输出 Fountain 格式；场标题、对白、场号依 [Fountain 语法](https://fountain.io/syntax/) 写，中文角色名需要时以 `@` 强制角色行。不要把普通 Markdown 场标题说成可导入的 Fountain 文件。

## 剧本创作提示词

交付时填好项目参数，不保留可从输入得知的占位符。原文过长则指出须一并提供的章节和段落。

```text
你是以真人写实短片为目标的改编编剧。将下列原文改编为可表演的正式剧本。
【原作与范围】{原文或需随提示词提供的段落}
【成片目标】{时长、语言、受众或制作限制}
【不可改变】{人物关系、人物选择、因果、叙事视角、揭示顺序、结局或开放落点}
先列有段落出处的原作节拍，并区分明示、推导和未知。用人物目标、阻力、选择与后果组织场次；用行动、对白、停顿和声音表达心理，不提前泄露角色或观众此时尚不知道的信息。写出完整正文，每场有内外景、地点、时间、动作和所需对白；不要用分镜或剧情摘要代替剧本。
只在原作留下的空间作现实可信的视觉转译。结尾停在原作的落点。另列所有补写、压缩或重排及理由；会改变核心事实的想法另列为待确认方案。
```

## 编剧审稿提示词

```text
对照【原文范围和原作锚点】与【剧本正文】做逐场审稿。按「场次、原文证据、问题、最小修订」列出会改变人物动机、事件因果、叙事视角和结局的问题；再核查信息揭示、对白可演性、无法拍摄的心理说明及节奏。区分硬性错误和可选创意。未经授权不改关键事实；只改受影响的场次，保留其 SC 编号，并报告改动。
```
