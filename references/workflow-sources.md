# 参考项目与采用方式

| 一手资料 | 采用方式 |
|---|---|
| [Fountain 语法](https://fountain.io/syntax/) 与 [Fountain 开源实现](https://github.com/nyousefi/Fountain) | 剧本区分场标题、动作、角色和对白；需要导出时使用正式的纯文本剧本格式。Fountain 不是改编或审稿系统。 |
| [Wonder Unit Storyboarder](https://github.com/wonderunit/storyboarder) 与 [官方工作流说明](https://wonderunit.com/storyboarder/) | 从剧本展开可排序的分镜，按画面管理动作、对白、时序和景别，先预演再投入生成；镜头描述是可检查的构图草案。 |

本技能只采用这些项目的工作方式，不复制源码、不要求安装，也没有实现对这些软件的自动导入、导出或调用。原作追溯、资产编号和 AI 生成提示词是本技能自己的制作约定。
